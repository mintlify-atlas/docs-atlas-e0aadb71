Cookie Monster can alert you to important in-game events through three independent channels: **browser notifications** (OS-level popups), **screen flashes** (a full-window color overlay), and **sound alerts** (a short audio clip). Each event type has its own set of toggles so you can mix and match — for example, enabling a sound for golden cookies but only a flash for wrinklers. Every alert channel is independently configurable per event.

<Warning>
  Browser notifications require explicit permission from your operating system and browser. The first time you enable a notification toggle in Cookie Monster, your browser will prompt you to grant notification permission for the Cookie Clicker page. If you deny the prompt, browser notifications will not fire until you manually grant permission in your browser settings. Screen flash and sound alerts are not affected by this permission.
</Warning>

## General Sound Setting

The **GeneralSound** setting (default: ON) controls how Cookie Monster interacts with the base game's volume slider:

- **ON** — CM respects the game's volume setting. If you have muted the game, CM sounds are also silenced.
- **OFF** — CM ignores the game's volume slider entirely. Sounds play at the volume set in each alert's own `Volume` control, even when the base game is muted. This is useful for keeping the game silent during gameplay while still receiving audio alerts for important events like golden cookies.

## Event Types

---

### 1. Golden Cookie

A golden (or wrath) cookie has appeared on screen.

<Tabs>
  <Tab title="Browser Notification">
    **Setting:** `GCNotification` | **Default:** OFF

    Sends an OS notification with the title "Golden Cookie Spawned" and the message "A Golden Cookie has spawned. Click it now!" Enabling this setting will prompt for browser notification permission on the first use.
  </Tab>
  <Tab title="Screen Flash">
    **Setting:** `GCFlash` | **Default:** ON

    Flashes the entire game window with the color set by **ColourGCFlash**.

    **Flash Color Setting:** `ColourGCFlash` | **Default:** `#ffffff` (white)
  </Tab>
  <Tab title="Sound">
    **Setting:** `GCSound` | **Default:** ON

    Plays an audio clip when a golden cookie spawns.

    **Volume:** `GCVolume` | **Default:** 100

    **Sound URL:** `GCSoundURL`
    ```
    https://freesound.org/data/previews/66/66717_931655-lq.mp3
    ```
  </Tab>
</Tabs>

### 7. Maximum Wrinklers

The maximum number of wrinklers allowed by the game has been reached.

When the wrinkler cap is hit, Cookie Monster fires the **WrinklerMax** alerts instead of the standard Wrinkler alerts for that final wrinkler. This lets you use a different (louder or more distinct) sound or flash color to signal that your wrinklers are full and ready to be popped for maximum cookie yield.

## Custom Sound URLs

Every sound alert accepts a direct URL to any audio file as its source. The URL must point directly to the audio resource (not an HTML page hosting the file).

<Tip>
  To use a custom sound, paste a direct link to an MP3, OGG, or WAV file into the Sound URL field for that event. Free sound libraries like Freesound.org provide direct preview links (ending in `-lq.mp3` for low-quality previews) that work well for this purpose. Make sure the server hosting the file allows cross-origin requests, otherwise the browser will block playback.
</Tip>
