Cookie Monster provides several real-time timing aids so you never miss a golden cookie or a buff expiry. The main **timer bar** gives you a compact, color-coded progress display for every active countdown. The **golden cookie timer** overlays a live second count directly on top of the golden cookie image. The **Grimoire bar** overlays your magic meter refill progress. And the **favicon** and **title** settings keep you informed even when the game is in a background tab.

## The Timer Bar

Enable the timer bar with the **TimerBar** setting (default: ON). When active, a slim bar appears either at the top-left or bottom of the game window (controlled by **TimerBarPos**), showing one row per active countdown.

### Timer Bar Position

**TimerBarPos** controls where the bar is anchored:

- **Top left** (default, value `0`) — the bar renders just below the top-left corner of the game canvas.
- **Bottom** (value `1`) — the bar renders at the bottom edge of the canvas, above the bottom bar if that is also enabled.

### Timer Bar Overlay

**TimerBarOverlay** controls what text is drawn on top of each progress bar segment:

| Value | Behavior |
|-------|----------|
| `0` — OFF | No text on bars |
| `1` — Seconds only | Each bar segment shows the remaining seconds |
| `2` — Full (default) | Each bar segment shows seconds **and** percentage remaining |

The overlay text for percentage applies to buff timers. The "Next Cookie" and "Next Reindeer" bars show seconds in their segments regardless of the overlay level when overlay ≥ 1.

### Autosave Timer Bar

**AutosaveTimerBar** (default: OFF) adds a dedicated countdown row to the timer bar that shows the seconds remaining until the game's next autosave. The row is only visible when the game's autosave preference is enabled.

## The Golden Cookie Countdown Timer

The **GCTimer** setting (default: ON) overlays a live second countdown directly on the golden (or wrath) cookie sprite the moment it spawns. The number updates every frame and counts down to zero as the cookie's lifespan expires. This gives you an immediate sense of urgency without needing to look at the timer bar.

<Tip>
  If you find the on-cookie number distracting, you can disable **GCTimer** while keeping the timer bar's "Next Cookie" row enabled. You get the pre-spawn countdown without a number on the cookie itself.
</Tip>

The timer is rendered as a transparent overlay with the same `z-index` as the game's shimmer layer, so it is always visible but does not block mouse clicks on the cookie.

## Grimoire Magic Meter Bar

When the Wizard Tower minigame is unlocked, the **GrimoireBar** setting (default: ON) adds a small overlay on the Grimoire magic meter showing the time remaining until the meter is completely full. This lets you quickly plan when you will be able to cast your next spell without doing arithmetic on the displayed magic fraction.

## Favicon Updates

The **Favicon** setting (default: ON) changes the browser tab favicon whenever a golden or wrath cookie is present on screen. At a glance you can tell from your bookmarks bar or tab strip whether a cookie is waiting to be clicked.

When the cookie despawns or is clicked, the favicon reverts to the standard Cookie Clicker icon.

## Tab Title Updates

The **Title** setting updates the browser tab title to reflect cookie timers and spawned cookies:

| Value | Behavior |
|-------|----------|
| `0` — OFF | Title is unchanged from the vanilla game |
| `1` — ON | Title is continuously updated with golden cookie / season popup countdown timers |
| `2` — Pinned tab highlight | Title only changes when a golden cookie or reindeer **spawns**, inserting a `!` prefix — the rest of the time the title is left alone |

<Tip>
  **Pinned tab highlight mode** is ideal when Cookie Clicker is running in a pinned browser tab. Most browsers show only the favicon for pinned tabs, but a title change still triggers the tab to visually indicate activity. Set Title to `2` and you will get a flicker on your pinned tab each time a golden cookie or reindeer appears, without the title constantly cycling through timer numbers.
</Tip>

## Color Meanings in the Timer Bar

The timer bar uses the same global color scheme as the building color system. The specific colors for each timer type are:

| Timer | Color |
|-------|-------|
| Next Cookie — min window | Gray (`#b3b3b3`) |
| Next Cookie — spawn window | Purple (`#ff00ff`) |
| Next Reindeer — min window | Gray |
| Next Reindeer — spawn window | Orange (`#ff7f00`) |
| Frenzy | Yellow (`#ffff00`) |
| Elder Frenzy | Green (`#00ff00`) |
| Clot | Red (`#ff0000`) |
| Click Frenzy | Blue (`#4bb8f0`) |
| Dragonflight | Pink (`#ff1493`) |
| Dragon Harvest | Brown (`#8b4513`) |
| Autosave | Purple |
| Other buffs | Purple (fallback) |

All color values are the defaults from the Colours settings group and can be customized there.
